# RiRxTunnel

A fast, secure and simple VPN application for Android.

## 📱 About RiRxTunnel

RiRxTunnel is an Android VPN application designed to provide a simple and reliable way to connect to secure VPN servers.

The application focuses on easy connection, server selection, connection stability and a clean user experience.

## ✨ Features

- 🔐 Secure VPN connection
- 🌍 Multiple server locations
- ⚡ Smart server selection
- 🔄 Automatic server failover
- 📡 Stable VPN connectivity
- 🎁 Rewarded Ad based premium server access
- 👤 User account support
- 🔥 Firebase authentication
- 🛡️ Secure production configuration
- 📱 Optimized Android experience

## ⭐ Premium Access

RiRxTunnel does not use a traditional subscription system.

Premium server access can be temporarily unlocked by watching a rewarded advertisement.

## 📲 Installation

1. Download the latest `RiRxTunnel-release.apk`.
2. Open the downloaded APK on your Android device.
3. Allow installation from unknown sources if Android asks.
4. Install and open RiRxTunnel.
5. Sign in and connect to a server.
